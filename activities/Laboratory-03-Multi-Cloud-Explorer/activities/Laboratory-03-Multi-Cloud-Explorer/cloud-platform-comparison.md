## Comparison Questions

**1. Which cloud provider offers the broadest range of services?**

Si AWS ang may pinakamalawak na range ng services dahil ito ang unang naglabas ng maraming produkto sa cloud computing space, mula sa compute, storage, hanggang sa mas specialized services tulad ng IoT at robotics. Dahil sa mahabang panahon nitong pagiging market leader, mayroon itong pinakamaraming feature at integration options kumpara sa Azure at GCP.

**2. Which provider best integrates with Microsoft technologies?**

Si Microsoft Azure ang pinaka-angkop para sa Microsoft integration dahil ito mismo ang gumawa nito. Direkta itong nakakonekta sa Windows Server, Active Directory, at Microsoft 365, kaya't mas madali at seamless ang migration para sa mga organisasyong gumagamit na ng mga Microsoft products.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

Si Google Cloud Platform ang pinakamalakas sa AI at Kubernetes. Ito ang orihinal na gumawa ng Kubernetes bilang open-source project, at malakas din ang mga AI/ML tools nito tulad ng Vertex AI at TensorFlow na parehong ginawa rin ng Google.

**4. Which cloud platform would you personally choose and why?**
For me, I would choose a project that matches the skills I already have. I prefer using platforms that are easy for me to understand, such as Laravel, PHP, MySQL, HTML, CSS, and JavaScript. This will help me finish the project more easily while also learning new skills along the way.
