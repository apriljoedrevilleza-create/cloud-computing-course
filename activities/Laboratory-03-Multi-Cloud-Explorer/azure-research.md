Brief Overview

Ang Microsoft Azure ay ang cloud computing platform ng Microsoft, na opisyal na inilunsad noong 2010. Malapit itong nakaugnay sa Microsoft ecosystem — kabilang ang Windows Server, Active Directory, at Microsoft 365 — kaya't madalas itong napipili ng mga organisasyong gumagamit na ng mga Microsoft technologies. Nag-aalok din ito ng malawak na services tulad ng compute, storage, database, AI, at hybrid cloud solutions. Isa ito sa top three cloud providers sa buong mundo kasabay ng AWS at GCP.
Global Infrastructure

Ang Microsoft Azure ay may malawak ring network ng Regions sa buong mundo, na sinasabing pinakamarami kung ikukumpara sa ibang providers dahil sa malawak na presence ng Microsoft. Ang mga Regions na ito ay iniuugnay sa Region Pairs para sa disaster recovery — kung saan awtomatikong nagre-replicate ang data sa kapareha nitong region. May mga Availability Zones din ito sa mga piling regions para sa mataas na availability.
Cloud Management Console

Ang Azure Portal ay ang web-based interface para sa pag-manage ng Azure resources. Mayroon itong customizable dashboard, at direktang naka-integrate sa mga Microsoft tools tulad ng Active Directory at Microsoft 365, kaya madali itong gamitin ng mga organisasyong Microsoft-based na ang setup.
Four (4) Core Services

Azure Virtual Machines – Nagbibigay ng scalable compute power sa pamamagitan ng virtual servers
Azure Blob Storage – Object storage service para sa unstructured data tulad ng documents, images, at videos
Azure SQL Database – Managed relational database service na based sa Microsoft SQL Server
Azure Active Directory (Azure AD) – Identity at access management service para sa authentication ng users at applications
Three (3) Advantages

Pinakamalakas na integration sa mga Microsoft products (Windows Server, Office 365, Active Directory)
Malakas na suporta para sa hybrid cloud setups (combination ng on-premises at cloud)
Mataas na antas ng enterprise-grade security at compliance certifications

Typical Enterprise Use Cases
Karaniwang pinipili ang Azure ng mga organisasyong gumagamit na ng Microsoft ecosystem, tulad ng mga unibersidad o kumpanyang may existing Windows Server at Active Directory infrastructure na gustong mag-migrate papunta sa cloud nang hindi nawawala ang compatibility.
