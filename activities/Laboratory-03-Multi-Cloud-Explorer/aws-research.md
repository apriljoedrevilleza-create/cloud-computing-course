Google Cloud Platform (GCP)
BRIEF OVERVIEW

Ang Amazon Web Services (AWS) ay ang cloud computing platform ng Amazon, opisyal na inilunsad noong 2006. Itinuturing itong pioneer sa industriya ng cloud computing dahil ito ang isa sa mga unang naghandog ng on-demand computing resources sa malawakang paraan. Nag-aalok ito ng malawak na hanay ng services — mula sa compute, storage, database, hanggang sa artificial intelligence at machine learning — na ginagamit ng mga startup hanggang malalaking enterprise sa buong mundo. Kilala ito bilang market leader sa cloud industry sa kasalukuyan.
GLOBAL INFRASTRUCTURE

 Ang AWS ay may pinakamalaking global infrastructure footprint sa kasalukuyan, na binubuo ng maraming Regions sa iba't ibang bansa (halimbawa: US East, Europe, Asia Pacific). Bawat Region ay hinahati pa sa maraming Availability Zones (AZs) — hiwalay na data centers na may sariling power, cooling, at networking para sa redundancy at fault tolerance. May karagdagan pang mga Edge Locations para sa content delivery (CloudFront/CDN) na malapit sa mga end users, na nagpapababa ng latency.
 CLOUD MANAGEMENT CONSOLE
 
 Ang AWS Management Console ay ang web-based dashboard kung saan pwedeng i-manage, i-configure, at i-monitor ang lahat ng AWS services. Mayroon itong search bar para mabilis makahanap ng services, at nagbibigay din ito ng access sa AWS CLI (Command Line Interface) at mobile app para sa remote management.
 Four (4) Core Services

Amazon EC2 (Elastic Compute Cloud) – Nagbibigay ng scalable virtual servers (compute power) para sa pagpapatakbo ng applications
Amazon S3 (Simple Storage Service) – Object storage service para sa pag-iimbak ng anumang uri ng data, mula sa files hanggang backups
Amazon RDS (Relational Database Service) – Managed database service na sumusuporta sa MySQL, PostgreSQL, at iba pa
AWS Lambda – Serverless computing service kung saan tumatakbo ang code nang walang kailangang mag-manage ng servers
Three (3) Advantages

Pinakamalawak na global infrastructure at pinaka-maraming services kumpara sa ibang providers
Malaki at aktibong community/ecosystem, kaya maraming documentation at third-party tools
Flexible pricing (pay-as-you-go) na angkop sa startups hanggang enterprises

Typical Enterprise Use Cases
Karaniwang ginagamit ang AWS para sa web at mobile application hosting, big data analytics, machine learning workloads, at disaster recovery dahil sa laki ng infrastructure nito na kayang mag-scale ayon sa pangangailangan ng negosyo.

🔵 Azure (azure-research.md)

Cloud Management Console
Ang Azure Portal ay ang web-based interface para sa pag-manage ng Azure resources. Mayroon itong customizable dashboard, at direktang naka-integrate sa mga Microsoft tools tulad ng Active Directory at Microsoft 365, kaya madali itong gamitin ng mga organisasyong Microsoft-based na ang setup.

Four (4) Core Services

Azure Virtual Machines – Nagbibigay ng scalable compute power sa pamamagitan ng virtual servers
Azure Blob Storage – Object storage service para sa unstructured data tulad ng documents, images, at videos
Azure SQL Database – Managed relational database service na based sa Microsoft SQL Server
Azure Active Directory (Azure AD) – Identity at access management service para sa authentication ng users at applications

Three (3) Advantages

Pinakamalakas na integration sa mga Microsoft products (Windows Server, Office 365, Active Directory)
Malakas na suporta para sa hybrid cloud setups (combination ng on-premises at cloud)
Mataas na antas ng enterprise-grade security at compliance certifications

Typical Enterprise Use Cases
Karaniwang pinipili ang Azure ng mga organisasyong gumagamit na ng Microsoft ecosystem, tulad ng mga unibersidad o kumpanyang may existing Windows Server at Active Directory infrastructure na gustong mag-migrate papunta sa cloud nang hindi nawawala ang compatibility.

🟢 GCP (gcp-research.md)

Cloud Management Console
Ang Google Cloud Console ay ang web-based dashboard kung saan pwedeng i-manage ang mga GCP resources. Kilala ito sa simple at clean na interface, at mayroon ding built-in na Cloud Shell — isang browser-based command line na direktang naka-access sa mga resources nang hindi kailangan mag-install ng anuman.

Four (4) Core Services

Compute Engine – Nagbibigay ng scalable virtual machines para sa iba't ibang computing needs
Cloud Storage – Object storage service para sa pag-iimbak ng malaking volume ng data
BigQuery – Serverless data warehouse na ginagamit para sa mabilis na pag-analyze ng malalaking datasets
Vertex AI – Platform para sa paggawa, pag-train, at pag-deploy ng machine learning models

Three (3) Advantages

Pinakamalakas sa larangan ng data analytics at artificial intelligence/machine learning
Mataas na performance dahil sa premium global network ng Google
Mahusay na suporta sa Kubernetes at containerized applications (dahil Google ang gumawa ng Kubernetes)

Typical Enterprise Use Cases
Karaniwang ginagamit ang GCP ng mga kumpanyang nangangailangan ng malalim na data analytics, machine learning research, at high-performance computing — tulad ng mga AI research companies na nangangailangan ng advanced computational power.
